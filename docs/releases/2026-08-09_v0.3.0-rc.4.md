## Resumo executivo

Consolida a sequência de hotfixes do fluxo combinado e um bugfix de UX. A
`v0.3.0-rc.3` comprovou em produção o contrato LLM neutro 2.0: a API aceitou o
strict schema com união `anyOf` e um caso real de teste chegou a
`WAIT_DOCTOR`. Esta candidata adiciona o ajuste de UX na tela de decisão
médica: após erro de validação no formulário, a página agora rola até o
primeiro campo inválido em vez de voltar ao topo.
