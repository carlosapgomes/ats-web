## Resumo executivo

Hotfix CRÍTICO que corrige o incidente aberto pela candidata `v0.3.0-rc.1`:
as factories `create_openai_llm1_client()`/`create_openai_llm2_client()`
vinculavam o modo strict json_schema aos schemas legados do contrato 1.1
(`Llm1Response`/`Llm2Response`). Em modo strict a API força estruturalmente a
saída ao schema fornecido; a resposta chegava sempre em formato 1.1 e falhava
em `Llm1ResponseV2.model_validate`, colocando 100% dos casos novos (EDA e
colonoscopia) em `FAILED`. A correção vincula as factories aos schemas V2 e
adiciona testes de contrato que falham contra qualquer regressão ao 1.1.

## Incidente corrigido

- Caso `1a700cc4-bb3f-416a-b2b0-f3a027d0027b` (ocorrência 4999496),
  `PIPELINE_FAILED` com `schema_version '1.1'` recebido pela validação 2.0.
- Causa: vínculo 1.1 + decodificação restrita do modo strict.
- Casos afetados em produção: tratados operacionalmente por encerramento
  administrativo + reapresentação (sem transição FSM de retomada a partir de
  `FAILED`).

## Specs atualizadas

- [`procedure-neutral-analysis`](../../openspec/specs/procedure-neutral-analysis/spec.md)
  — novo requisito: dispatch LLM de produção vincula strict schema
  exclusivamente ao contrato 2.0, protegido por testes.

## Risco residual e smoke obrigatório

O schema V2 do LLM1 usa `oneOf` + `discriminator` + `$ref` na serialização
(itens de `requested_procedures`). A aceitação dessas construções pela API
OpenAI em strict mode só é comprovada com chamada real. Antes de liberar o
intake ao NIR:

- [ ] 1 relatório de colonoscopia conhecido como bom chega a `WAIT_DOCTOR`;
- [ ] 1 relatório de EDA conhecido como bom chega a `WAIT_DOCTOR`;
- [ ] `structured_data` persistido com `schema_version: "2.0"`.

## Rollout e rollback

- Sem migration: estado de banco idêntico antes/depois.
- Servidor temporário: `git pull --ff-only` + `docker compose build` +
  `up -d` (web/worker/pdf_worker).
- Rollback: revert do commit + rebuild; só se justifica se o hotfix
  introduzir falha nova (o estado anterior mantém o incidente ativo).
