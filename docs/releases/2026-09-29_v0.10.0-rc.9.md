## Resumo

Correção duradoura do incidente pós-rc.8 (filtro `<select>` sem labels e sem
filtrar por JS velho cacheado contra HTML novo): os dois templates de fila
passam a referenciar seus JS via `{% static %}`, de modo que em produção as
URLs carreguem o hash do manifest (WhiteNoise, já ativo) e cada deploy sirva
HTML+JS consistentes. Sem mudança de comportamento.

Entregas (change `openspec/changes/queue-filter-cache-busting`, 1 slice):

- `templates/scheduler/queue.html` + `templates/doctor/queue.html`:
  `{% load static %}` e `{% static 'js/…_filter.js' %}` (eram as únicas
  referências hardcoded em `templates/`);
- asserts novos de tag estática por suíte de fila.

## Operação

Sem migration, prompts, dependências, mudança de banco, FSM ou dados
persistidos. A publicação da imagem não executa deploy ou reprocessamento.

Deploy padrão por troca de imagem. Rollback para `v0.10.0-rc.8` é seguro e não
exige ação de banco. Após o deploy, confirmar na origem que os `<script>` das
filas trazem hash (`…filter.<hash>.js`); browsers/CDN com o JS velho convergem
no TTL (hard refresh resolve resíduos).

Smoke recomendado:

1. ver o HTML servido das filas com `src` com hash;
2. trocar o select de tipo nas duas filas — filtro imediato, labels visíveis;
3. aguardar o poll (20s) sem reset;
4. login local e público saudáveis.
